Privacy policy

rclone personal requests full Google Drive access so the operator can list, read, upload, update and delete Drive files using rclone. rclone uses Drive data to perform the file operations requested by the operator, including copying files between Drive and systems the operator controls.

OAuth credentials are stored in the operator’s private rclone configuration. File copies are retained at the destinations the operator chooses. This website does not request Drive access or receive Drive files or OAuth credentials. The operator can revoke access in Google Account settings.
